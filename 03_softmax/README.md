# 03. 소프트맥스 (Softmax)

## 한 줄 요약
점수(logit)를 **합이 1인 확률**로 바꾼다.
최고점 빼기 → 부풀리기(e^x) → 더하기 → 나누기.

## 왜 필요한가
- 점수를 그냥 합계로 나누면 음수 점수에서 확률이 마이너스가 된다.
- e^x는 어떤 값이든 양수로 바꾸고, 큰 점수를 더 크게 키워 1등을 잘 드러낸다.

## 핵심 구현 포인트

| 포인트 | 이유 |
|---|---|
| 최고점 빼기 | e^1000 같은 오버플로를 막는다. 모두에게 같은 값을 빼므로 결과는 같다 |
| 온도로 나누기 | 낮으면 결정적(얌전), 높으면 다양한(엉뚱한) 출력 |
| log_softmax | log(softmax)는 작은 확률이 0으로 반올림되면 log(0) 에러. log 상태로 바로 계산 |

## 디코딩 (다음 토큰 고르기)
- `greedy`: 항상 1등. 결과가 같지만 반복적이고 지루해질 수 있다.
- `top_k_filter`: 상위 k개만 남기고 -inf로 가린 뒤 소프트맥스 → 엉뚱한 후보 제거.
- `sample`: 확률대로 제비뽑기. 같은 질문에도 답이 달라지는 이유.

## 손실 함수: Cross Entropy
`loss = -log(정답 토큰의 확률)`
- 정답 확률 65.9% → 0.417, 9.9% → 2.317
- LLM 학습은 이 값을 줄이는 방향으로 진행된다. (07. 경사 하강법과 연결)

## 배운 점
- 소수는 `==` 대신 오차 범위를 두고 비교해야 한다. (`0.1 + 0.2 != 0.3`)
- 랜덤 코드는 seed를 고정하거나, 많이 실행해 비율을 보는 방식으로 테스트할 수 있다.
- -inf를 넣으면 e^(-inf) = 0이 되므로 '가리기(mask)'에 그대로 쓸 수 있다.
  단, 모든 값이 -inf면 계산이 깨지므로 따로 막아야 한다.

## LLM과의 연결
- 출력층: 다음 토큰 후보들의 점수 → 확률 → 디코딩
- 어텐션 내부: "어떤 토큰을 얼마나 볼까?" 점수 → 확률 (05. 어텐션)
- 마스크: 미래 토큰 점수를 -inf로 바꿔 확률 0으로 만든다
